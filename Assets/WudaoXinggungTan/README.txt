⚠️ Troubleshooting
If you encounter the following error when pressing Play:
ZenjectException: Could not fill contract 'CoreScene' for scene…
This likely happened because the folder structure was changed. To fix it:
1. Go to Tools → PracticAPI → Scene → Select Default Scene
2. Select the CoreScene located at: Assets/PracticAPI/AdvancedGame/Core/Assets/Scenes/CoreScene.unity
